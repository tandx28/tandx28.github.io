## The work

Over ten months I worked on a platform that plans and tracks last-mile deliveries.
The code is not public, so this page describes what I did rather than how the system
works inside.

- Built **Angular and TypeScript** features in the web app.
- Wrote and extended **C#/.NET** API endpoints, and tested them with Swagger and Postman.
- Investigated **mismatches in delivery-job payloads** with data analysis, scripts and
  visual reports, and traced them back to their cause.
- **Refactored** existing components using design patterns so they were easier to
  maintain and test.

## What I took from it

How a real team ships: reading an unfamiliar codebase, writing changes small enough
to review, and checking an API from both ends before calling it done.
